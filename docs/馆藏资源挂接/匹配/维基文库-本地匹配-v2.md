## v1 脚本的三个 bug（本轮修复）

### 1. Header 字段切分漏掉最常见写法 ★影响最大

```python
re.split(r'\|(?=[a-z_A-Z]+=)', body)     # v1：要求 | 紧跟字段名
re.split(r'\|\s*(?=[a-zA-Z_0-9]+\s*=)', body)  # v2：允许 | 与字段名间有空白
```

wikisource 最常见的是对齐写法 `| author   = 何晏`，`|` 后有空格。
v1 全部解析失败 → 误归「无作者字段」。这是待查率高达 80% 的主因。

### 2. Header 主体被子模板提前截断

`notes` 字段常内嵌 `{{Textquality|50%}}`，而 v1 用 `[^}]*` 取 Header 主体，
会在子模板第一个 `}` 处断掉，导致 author2/author3 等后续字段错位混入，
甚至把带换行的内容写进 TSV 撑爆行结构。v2 允许一层嵌套：

```python
r'\{\{\s*(?:[A-Za-z]+\s+)?[Hh]eader\s*\|((?:[^{}]|\{\{[^{}]*\}\})*)\}\}'
```

### 3. TSV 无转义

任何字段含换行/tab 都会破坏行结构。v2 统一 `re.sub(r'\s+', ' ', ...)` 兜底。

## v2 新增的解析覆盖

| 情况 | 例子 | 处理 |
|---|---|---|
| Header 变体模板 | 范文正公集 `{{Collection header\|author=范仲淹}}` | 正则加 `(?:[A-Za-z]+\s+)?` 前缀 |
| 四庫全書本 `{{SKQS header}}`（**无 author 参数**）| 松隱集 → 正文首行「宋　曹勛　撰」| 按「朝代+人名+撰/著/編…」抽正文署名 |
| 只有分卷子页、无顶级页 | `松隱集 (四庫全書本)/卷01` | 建子页索引回退；`全覽` 页排后 |
| 合刊本重定向带锚点 | 箋紙譜 → `歲華紀麗譜#牋紙譜` | **保留锚点**，否则只能指到母书 |
| 繁简／异体混用 | 周學海 vs 周学海 | 比对前 opencc t2s 折简（+49 条确认，零回归）|
| `override_author` | 續漢書「〔晉〕司馬彪 撰」 | 加入 AUTHOR_KEYS |
| `translator`（佛典） | 藥師琉璃光如來本願功德經 → 玄奘 | 加入 AUTHOR_KEYS |
| `noauthor` 里其实有作者 | 後漢書 → 范曄/司馬彪/李賢/劉昭 | 加入 AUTHOR_KEYS（最低优先级）|
| 正文首部 `作者：` | 靈樞識（整本导入，非 wikitext 结构）| 无 Header 时回退抽取 |
| 重定向 | 老子衍 → 船山遺書/老子衍 | **追一跳**后继续校验（v1 只标待查）|
| 消歧义 `{{xqy}}` 等变体 | 松隱集（曹勛本/朴翊本）| **按我方作者选版本**后继续校验 |
| `{{versions}}` 版本汇总页 | 大學 | 单列一类，不当正文页 |

作者字段优先级：`author` > `override_author` > `translator` > `noauthor`。

「无作者字段」进一步拆成 `双方均无作者` / `ws无作者字段` / `我方无作者`——
第一类（佛经、辑佚书）可低置信度接受，与后两类的处置完全不同。

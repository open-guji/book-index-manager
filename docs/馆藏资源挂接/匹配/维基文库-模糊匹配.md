# 维基文库模糊匹配（补精确匹配之漏）

> 执行日期：2026-09-07
> 脚本：[scripts/match_wikisource_fuzzy.py](../../../scripts/match_wikisource_fuzzy.py)
> 前置：[维基文库-本地匹配-v2.md](维基文库-本地匹配-v2.md)（精确书名匹配，已写入 733 条）

## 为什么要做

精确书名匹配只覆盖 **4.8%** 的未关联 Work（4,221 / 88,428）。
抽查未命中者发现瓶颈**不在维基文库没有内容**，而在书名差一两字就整条漏掉：

- 《人境廬詩》→ ws 作《人境廬詩**草**》
- 《覺世名言》→ ws 作《覺世名言**十二樓**》
- 《御批通鑑輯覽》→ ws 有《通鑑輯覽》（我方多「御批」）

## 目标集怎么定的

从 95,447 条 Work 里筛：

| 条件 | 剩余 |
|---|---|
| 无 wikisource 资源 | 87,695 |
| 排除 `loss_status=lost`（佚书维基文库本就不会有）| — |
| **必须有 authors**（无作者则无从校验，宁可不做）| — |
| 排除精确匹配已覆盖的书名 | **60,920** |

## 召回：构造确定的键去查表，不做相似度搜索

先试过 3-gram 倒排索引，**放弃**：最大桶 205 万条（《四庫全書》《欽定古今圖書集成》
这类超高频前缀），用它召回等于全表扫描。

改为构造候选键直接查哈希表，两个方向：

- **A：ws 名 = 我方名 + 尾缀** —— 加 `草/集/稿/錄/序/詩集/全集/續集…`；
  另用前缀索引取「以我方名开头且只多 ≤4 字」者。
- **B：ws 名 = 我方名去修饰后的核心** —— **枚举连续子串**（长度 ≥3 且 ≥ 原名一半，长者优先）。

> B 起初用固定词表（`御批/御製/新刻/後集…`）剥前后缀，候选生成率只有 **1.6%**。
> 修饰语千变万化，词表永远补不全；改枚举子串后升到 **15.5%**。书名短，子串数可控。

## 定案：作者必须完全匹配，且书名差额不得改变「是哪部书」

**第一道**：`author_match_score == 1.0` 才考虑（沿用 v2 的比对，含 opencc 折简）。
作者对不上一律拒绝——库内同名异书极普遍。

**第二道（本轮新增，关键）**：作者对上也不够。实测首批 21 条命中里**过半**是
「作者对但书不对」，光靠作者拦不住：

| 类型 | 例 | 判据 |
|---|---|---|
| 只是序跋/目录 | 唐韻 → 唐韻**序**；毛詩傳箋通釋 → …**自序** | 差额 ∈ 序/敘/跋/凡例/目錄… |
| 补遗≠正编 | 萬曆野獲編**補遺** → 萬曆野獲編 | 差额 ∈ 補遺/續編/附考/外集/合集… |
| 母子篇 | 九歌**二首** → 九歌；子夜吳歌**之夏歌** → 子夜吳歌 | 差额含篇数或「之」 |

`diff_is_semantic(a, b)` 实现之，命中前必过。这批落 `blocked`，写进 TSV 但**不写库**。

### 一条试过又撤掉的规则

曾加「差额自成篇题（末字为 說/論/記/譜…）就拦」，为捞《種桑說養蠶說》vs《種桑說》。
但它误伤《牡丹亭**還魂記**》vs《牡丹亭》——「還魂記」是同书别名的一半，不是另一篇。
二者从字面判不出分别，故**舍此规则**：宁可放过合编，不可拦住正解。

## 结果

| 目标 | 60,920 |

写入 308/308 全成功，`check-index` 通过。
库中有 wikisource 资源的 Work：7,752 → **8,059**。

### 护栏收紧了四轮

每轮全量跑完抽审命中项，发现漏网就补词表再跑：

| 轮次 | 命中 | 拦截 | 该轮补的 |
|---|---|---|---|
| 1 | 396 | 126 | 序跋、补遗、篇数 |
| 2 | 350 | 172 | 佚文、續/後冠首、圖/讚/本紀 |
| 3 | 318 | 204 | 注本、載記/卷末、二筆三筆 |
| 4 | **308** | **215** | 箋、校譌/增釋/重訂、詩話/詞話、目錄序論 |

**拦截量占作者匹配项的 41%**（215 / 523）。若只靠作者校验，这 215 条会全部误写。

典型拦截：《水經注箋》≠《水經》、《升庵詩》≠《升庵詩話》、《論衡佚文》≠《論衡》、
《續唐會要》≠《唐會要》、《晉書載記》≠《晉書》、《九歌二首》≠《九歌》。

### 放行的典型（古籍著录常态）

冠姓《崔宫教集》→《宫教集》、冠地《南陵無雙譜》→《無雙譜》、
刊记《新刊初學記》→《初學記》、堂号《亦政堂重修宣和博古圖錄》、
别名《牡丹亭還魂記》→《牡丹亭》、加尾《人境廬詩》→《人境廬詩草》。

### 一条已知漏网

《觚賸觚賸續編》→《觚賸續編》：差额「觚賸」是前缀自身重复，不属任何词表。
孤例，且我方书名本身疑似著录重复，未为它单开规则。

## 复现

```bash
# 依赖：先由 v2 流程备好 dump 与 title-index
python scripts/match_wikisource_fuzzy.py --sample 3000 --out /d/tmp/fz.tsv
python scripts/match_wikisource_fuzzy.py --out /d/tmp/fz_full.tsv
```

TSV 列：`verdict, work_id, work_title, work_authors, ws_title, ws_url, ws_author`
- `fuzzy-confirmed` —— 作者完全匹配且过语义护栏，可写入
- `blocked` —— 作者对但书名差额显示非同一书，**不可写**，留档备查

# 四庫全書存目叢書目录抓取

> 日期：2026-04-26  
> 状态：✅ 完成（4519 条，覆盖 1198 册）

## 数据来源

**维基文库**主页：https://zh.wikisource.org/wiki/四庫全書存目叢書

但 HTML 渲染后会被 wikitable 隐藏（页面只显示经部+史部）；通过 MediaWiki API 拉 wikitext 源代码即可拿到完整 4 部目录：

```
https://zh.wikisource.org/w/api.php?action=parse&page=四庫全書存目叢書&prop=wikitext&format=json
```

## 输出文件

`D:/tmp/cunmu_catalog.tsv`，4519 条

字段：
- `section` 部类（经部/史部/子部/集部）
- `ce` 册次
- `title` 书名
- `juan_count` 卷数（如 `十二卷`、`不分卷`、`十五卷 首一卷 易學啓蒙訂疑四卷`）
- `dynasty` 朝代（如 `宋`、`明`、`北魏`）
- `author` 作者名
- `role` 角色（撰/輯/纂/注/疏/編 等）
- `edition` 版本+收藏馆藏
- `raw` 原始 wikitext 行

## 经验

1. **wikitable 渲染隐藏内容**：维基文库主页在 HTML 里只显示经部+史部，但 wikitext 源里 4 部全有
2. **维基 API 取 wikitext**：`?action=parse&page=...&prop=wikitext&format=json`
3. **wikitext 格式规整**：每册一段「经部 第一册 (...)」+ `* '''書名X卷''' ''朝代 作者 角色 版本''`
4. **多卷复合标题**：`'''書名X卷''' '''首一卷''' '''XX四卷'''` 需要拼接处理

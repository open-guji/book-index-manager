## 工作原则

1. 每个数据源建一个独立 md 记录：方案 → 测试 → 结果 → 经验
2. 脚本统一放在 [scripts/](../../../scripts/)（如 `match_wikisource.py`）
3. 写入索引必须用 `book-index add-resource`，不能直接写 JSON
4. 匹配必须有作者校验，纯书名匹配错误率高（参考 memory/feedback_author_match）

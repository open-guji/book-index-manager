## 二、口径

1. **链接**：KORCIS Open API 的 `detail.do?rec_key=` 是 XML，不是人读页；网页详情页只收带会话的 POST。详情 XML 里 `LOCAL_CONTROL_NO`（如 `KOL202600003`）就是国中数字馆藏的控制号，KORCIS 详情页「원문」按钮用的正是它（`fnOriginalPop('KOL…')` → 国中阅览器）。资源 url 用国中按控制号的 GET 检索 `https://www.nl.go.kr/NL/contents/search.do?srchTarget=total&kwd=<控制号>`，页内有该书各册的阅览入口。
2. **只写互联网公开的**：国中检索页每册标「자료이용」。`[관외이용]`（馆外可用）才写；`[국립중앙도서관,협약도서관]`（只限国中及协约馆）不写。
3. **资源项**：`id=nlk`，`types=[image]`，`group=korcis-<rec_key>`，`metadata`＝`korcis_rec_key`、`nlk_control_no`、`holder`（KORCIS 所藏馆名，原文韩文）、`call_number`、`part`（题名尾的存卷，如「卷1-7」）、`edition`（版种＋刊年）。label「韓國國立中央圖書館數字化藏本：版本」。`resource-site.json` 登记 `nlk`。
4. **适配器归一**：题名尾 `. 卷1-3`／`, 第6, 9` 切进 `part`；责任者 `名(朝代) 撰 ; 名(朝代) 編` 改成国图体例 `(朝代)名撰；(朝代)名編`。Profile 照国图，但不用版本串判朝代（多为朝鲜年号）。
5. **二道闸**（`kfilter.py`，宁缺毋滥，命中改存疑不写）：F1 题名带前置括注（`(原本備旨)論語集註`）而 Work 题名不含括注字；F2 站方责任者含注／註／口義／評／譯／補等次要责任者，其名不在 Work 责任者里（可能是另一部注本 Work）；F3 版本串公元年早于 Work 首位著者朝代起年（本批 0 条）。

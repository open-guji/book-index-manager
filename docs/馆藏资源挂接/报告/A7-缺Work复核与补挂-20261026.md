## 二、工具（`tools/馆藏资源挂接/a7/`）
| 脚本 | 作用 |
|---|---|
| `screen.py <工作目录>` | 读 `<工作目录>/eng2-{nlc,ndl}/matches.tsv`，取「无」档且未挂的记录，对现库找同作者近题、近题无作者、近题异作者等，分 K／H／D／N／C／L／G／X 档，写 `screen.tsv` |
| `linkplan.py <工作目录> <源>` | 把 `verdicts.txt` 里的 S 判（S1–S3 指 top3 第几名）和引擎写入计划并起来，去掉已在库 group，按 K9 截额，写 `linkplan-<源>.jsonl`（`basis` 列标来源） |
| `authors.py` | 国图著者串 →  Work `authors[]`（朝代、责任方式、「等」、僧名「釋」、外国名标拿不准），供建新 Work 用 |

判词格式：`review.tsv` 每组一行，`verdicts.txt` 每行「组号 判词」。判词有四种：S<n>＝同 top3 第 n 名；N＝新书；?＝拿不准；M＝近代。

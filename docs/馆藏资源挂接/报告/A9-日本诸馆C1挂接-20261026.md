## 二、口径与规则（本批新加的）
1. **写入单位（藏本）**：匹配以记录为单位，写入以藏本为单位，`group`＝`<前缀>-<藏本代表记录号>`。藏本的认定：东大＝`holding_id`，書陵部＝多册书总条 `parent_id`，慶應＝（题名,责任者,版本）相同者，ARC＝去分册号的 `holding_id`，东文研／名大＝每条自成藏本。同 Work 同藏本只写排序最前一条（`adapters/jpc1.finalize`）。
2. **url**：取藏本代表记录的详情页；書陵部取总条 `Toshoryo/Detail/<总条号>`（分册页在总条页内可达）。慶應站方给的是 `http://`，统一改 `https://`（站方 301 到 https）。
3. **metadata**：各馆记录号键 `utokyo_record`／`ioc_nu`／`shoryobu_id`／`keio_record`／`arc_record`／`nagoya_record`，另有 `call_no`（索书号）、`edition`、`iiif_manifest`（有 IIIF 清单的馆）。ARC 另有 `holder`（实际藏家：UCLA、芝加哥藝術博物館等）。
4. **label**：`<馆简称>藏本：<版本>`；东文研若属丛书作`東文研藏本：《舊小說》所收本`（丛书名去集次册次）。
5. **责任者解析**（`jpc1.parse_author`）：括号内是朝代当朝代、是役割当役割、其余（字号、子目名、`【著者】`标签）丢弃；朝代可前置（「明 李賢」）也可粘连（「唐李嶠」），粘连时两种写法都进名集合；役割词只剥**一个**（「吳敬梓撰」剥「撰」不剥「梓」）；只取主责任者（撰著編注等），校／訂／刊／序跋等次要役割仅在无主责任者时补用。
6. **刹车**（六馆都开）：
   - `lead_brake`：站方**首位**责任者须与 Work 相合，否则 `A_SECONDARY_ONLY` 降存疑（挡注疏者／校者当主名的情形）；
   - `alt_sibling_brake`：仅凭 Work 的附加题名命中、且有兄弟 Work 或多出责任者 → `ALT_TITLE_SIBLING` 降存疑；
   - `LOCAL_PART` 扩充：題名尾「殘／存」、「存卷 1 至 3」式残本、書陵部无总条而括注以「巻／第」起的零本（「巻４９３（首尾欠）」）、总条标「零巻」的分册、东文研折子（「牡丹亭(勸農)」）一律降存疑。
7. **人核否决**（`match_engine/data/human_verdicts.tsv` 新增 5 行）：東文研 `說文解字`（库内 Work 著者为段玉裁注，站方为段注本但库内条目是注本还是本文不明，从严不挂）、書陵部 `李白詩`（新井白石抄录选本）、ARC 三条画谱（八種画譜之一种，仅凭附加题名命中《黃氏畫譜》）。

## 设计点
- `Resources.scan`：Work＋其下 Book（以 Book.work_id 归属）的资源；`existing_res`＝Work 或其 Book 有任何资源；`already_linked(source, record_id, work_id)` 按口径 K 的 metadata 键（nlc_fid／kokusho_bid／ndl_record／naikaku_file_id）。同一记录挂在别的 Work 上**不算**已挂。
- `groups.apply_group_split`：同组确定档指向 >1 个 Work → 全组降存疑，加 `GROUP_SPLIT`。
- `exclusions.load_exclusions(overview_root)`（先后规则钩子，只标注不改判定，引擎在 matches.tsv 加 `excluded` 列）：R2 读 ledger（action=hold 且 reason 前缀三种，指向 work_id 或 reason 里的 Work id），R3 读 `work_side=draft`，R7 读 dupx 清单。当前读到：R2 57 个 id（52 个在正式库）、R3 37,723（在正式库 0，符合“尚未升格”）、R7 1,288（均在正式库）。

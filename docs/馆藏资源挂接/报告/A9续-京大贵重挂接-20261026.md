## 二、适配器 `adapters/kyoto.py`（接 A9 公共层 `jpc1.py`）
1. **写入单位**：一个 item 一个藏本，`group=kyoto-<レコードID>`。站方索书号不能当藏本：同一个号下常是不同的书，比如「醫學統宗」各子目，「帝範」和「帝鑑図説」也同号。
2. **题名**：
   - 去掉角書「(秘伝)」「(新編)」「(付釈音)」和【宋版】一类标签。
   - 卷次写在前面的，如「法苑珠林 巻第75」「昌黎先生集 巻1-4」「大般若波羅蜜多経 巻328」，切下来记 LOCAL_PART。
   - 「36 巻」去掉中间的空格；「周易 周易上経、周易下経…」这类子目列表只取第一段。
   - 首轮没有处理卷次写在前面的情形，84 条误落「无」档；修正后重跑，这 84 条改落存疑，并新增 3 条确定。
3. **版本**：站方「形態・版情報」多是尺寸装订（「刊 和大」「27 (cm)*折帖本」），所以改由 出版情報＋出版年（和暦）＋写刊の別 拼。尺寸串里的「和／支」是和本、支那本，拼成「和刻本／和寫本／中國刊本」。
4. **刹车**：同 A9 六馆，开 `lead_brake` 和 `alt_sibling_brake`。
5. **注册点**：`tier.JPC1`、`writeplan.JPC1／SITES／_JPC1_KEY`（`kyoto_record`）、`workindex.RECORD_KEY／SITE_OF_SOURCE`、`write_plan_apply_r3.SITE`（京大）。
6. **单测**：`tests/test_kyoto_adapter.py`（题名切分、版本拼法、load→make_item 的形状）。

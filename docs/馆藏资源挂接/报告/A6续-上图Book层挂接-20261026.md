# A6续 上图藏书 Book 层书目页挂接（2026-10-26）

> 「A11 目录 - 账号A备用」项目「挂接上海图书馆馆藏资源」线程。计划见 ai-team `domain/目录与资源/设计/2026-10-图书馆资源搜集与挂接计划/`（排班表「A6续」行）；输入是 A6 研究（book_index_json `library_data/_匹配/上海圖書館藏書/A6-研究-20261025/`）。

## 一、口径

- 上图藏书详情页（`gj.library.sh.cn/org/info/shl?uri=…instance/<id>`）是 OPAC 书目页，**没有影像和全文**。按 K5（馆藏记录不写成 Work 资源）与 A6 建议，**Work 层不写**。
- 本批只做 A6 的备选方案：在 A6「Book 年同」档（上图记录 → 唯一在世 Work → 该 Work 下有 `provenance: 上海圖書館`、版本类型与公元年都相同的 Book）上，往 **Book 层**追加一条书目页链接。
- 资源项：`id=shlib`、`types=["catalog"]`、`group=shlib-<instance>`、`group_role=origin`、`metadata.shlib_instance／shlib_work／edition／publisher／extent`；`resource_groups` label「上海圖書館藏本書目：<版本>」。每 Book 上图条目 ≤3（K9）。
- Work 层是否也挂（约 7 万条）由用户在线程卡片上定；用户未改口径前只做 Book 层。

## 二、写入：日本诸馆无影像确定档的 Book 层书目页

来源：A9（10-26 报告）留下的「无影像的确定档 3,748 条」，K3 禁止挂 Work 层；用户 10-26 定「无影像的书目页可挂 Book 层」。本次在现库上重跑引擎：

| 馆 | 确定档 | 其中无影像且未挂 |
|---|---:|---:|
| 書陵部 | 2,174 | 1,767 |
| 名大 | 2,147 | 2,120 |

对它们跑 `book_candidates.py --has-image 0`（本次给脚本加了 `--has-image` 参数，默认行为不变），按 K2「库内已有 Book、版本一致、恰一个」出候选：

| 去向 | 書陵部 | 名大 |
|---|---:|---:|
| STRONG（年号与年数、版式类型都相同，恰一本） | 164 | 101 |
| MEDIUM（只到朝代级） | 176 | 36 |
| AMBIG（同版 Book 不止一本） | 214 | 73 |
| ERA_ONLY／ERA_AMBIG（站方没写版式） | 2 | 81 |
| 无同版 Book | 988 | 440 |
| 库内无 Book | 71 | 199 |
| 站方版本不足／仅朝代无版式 | 116 | 1,153 |

**只写 STRONG。** MEDIUM 例如站方「明版」对 Book「明程榮刻本」，只有朝代一致，不够；AMBIG、ERA 档同理不写。

STRONG 265 条的筛法：
1. 机械剔除 67：站方或 Book 版本串带覆刻、重刊、再版、模刻、据、影印、补修、增、续、校，或 Book 是「甲刻;乙刻」合成版本。
2. 剩 198 条我逐条看站方版本与 Book 版本（年号年、刊者、日本版／中国版），再剔 7 条刊者对不上或重刊字样漏网：唐陸宣公集（春暉堂≠周右吳紹元）、三魚堂文集（琴川書屋≠嘉會堂）、古今文字通釋（金筆軒≠龍溪林維源）、四書大成（武林書房≠浙撫張鵬翮）、浙西六家詩鈔（柴山館≠紫微山館，同书另一条保留）、味經齋遺書（重栞）、論語正義（刊者不明）。
3. 终稿 **191 条／173 个 Book**（書陵部 140、名大 51），清单 `人工判挂_record_id.txt`，计划 `write_plan.jsonl`。

形状：`id`＝`shoryobu`／`nagoya-u`（与 Work 层同站 id），`types=["catalog"]`，`group=<前缀><记录号>`，`details` 注明无线上影像，`metadata` 记录号／版本；label「書陵部藏本書目：…」「名大藏本書目：…」。

**检查**：191 个书目页链接逐个请求，全部 200（名大页内题名与计划一致 49／51，另 2 条页内未出现 Work 题名首二字，站方题名写法不同，保留；书陵部页面是动态页，只核得 200）。门禁：`check_schema --paths` ERROR 0、`check_v2 --paths`（174 档）ERROR 0，`verify --strict` 输出与 main 逐行相同。只追加 resources／resource_groups／revision／revised_at／ai_note。

**没有第二位独立盲检。** A6 做了 185 条盲检；本批规模小、全部我自己逐条判，没开子 agent。要更稳可抽 40 条另行盲检。

## 二、做法

1. **适配器** `adapters/euro.py`：各馆题名取含汉字的一段（柏林「罗马字 = 汉字」取右侧、cudl 去罗马字、onb「X X」收成一段、去 `@`／补题方括号），` : `／` ; `／卷册注切进 rest；卷数取「N卷／N 卷／汉字卷数」。只出有影像的记录。
2. **拼音责任者**：loc 责任者全是拼音（`Chen, Jiru, 1558-1639, bian ji`）。`tier.Profile.pinyin` 打开时，站方拼音名与 Work 著者的拼音（pypinyin，多音字全组合）比。loc 役割全是 xu／jiu xu／ba／ti／ke／cang ban／collector 之类（序跋、旧序、刻、藏版、收藏）的人不算责任者。六馆都开 `lead_brake`（首位责任者须与 Work 相合）与 `alt_sibling_brake`。
3. **多册书成组**：bsb 用 `parent_b3kat_id`、柏林用 `parent_ppn`，其余馆按「题名＋责任者＋版本」成组；一套内各册的卷册注不当残本。写入时一套只写一项，group＝`<id>-<整套号或首册号>`，`metadata.volume_count`，`details` 注「多冊本，站方分 N 條著錄；此處鏈接其中排序最前一條」。
4. **资源项形状**（新站点，K6–K8 新键）：`id`＝`bsb`／`sbb`／`loc`（另 `cudl`／`onb`／`bnf` 已备）；`types: ["image"]`；`url`＝站方阅览页（bnf 用 Gallica、onb 用 ABO 阅览器，书目页无影像）；`metadata`＝`<id>_record`、`iiif_manifest`、`shelfmark`、`edition`；`resource_groups` label「某館藏本：版本」。`resource-site.json` 登记 bsb／sbb／loc 三站。
5. **二道闸**（复核脚本 `review.py`，剔 15 项）：方志 Work 题名带年号前缀而站方年份不在该年号内（4）；站方年份早于著者朝代（9，多为 loc 的占位年 1573，从严一并剔）；站方责任里有「某某箋註／輯註」而某某非 Work 著者、Work 题名无注字（2，K14）。

## 三、核对

- **盲检**：两轮各 200 条随机样本（种子 20261026／99），逐条看 Work 题名、著者、朝代与站方题名、责任、版本。
  - 首轮错 1：loc《陽穀縣志》1716 年王時來本被挂到同题 Work（Work 著者王天壁，loc 里王天壁只是「jiu xu」旧序作者）。原因是役割只看最后一个，「zuan xiu, xu」整人被丢、首位刹车失效。改为「全部役割都是非著述才丢」，加 jiu／collector 等，重跑后该条改挂王時來 Work（正确），loc 确定 822→838。
  - 次轮（改后）错 0；另 2 条注本（bnf 李義山詩集朱鶴齡箋註、李太白文集王琦輯註）由新加的注本闸剔掉。
  - 两轮表：`blind200.tsv`、`blind200_r2.tsv`。
- **链接内容抽检**（`linkcheck.py`，样本 `linksample.json`）：bsb 30/30（阅览页 200 且页内含记录号）；柏林阅览页是 JS 壳（假号也 200，无判别力），改查同号 IIIF manifest：真号 30/30 为 200 且含 PPN，假号 404；loc item 页对云端出 Cloudflare 质询，改查同 item 的 `?fo=json`：30/30 为 200、含 LCCN、`digitized: true`（其中 1 条首查 503，复查 200）。
- **库内校验**：改动 1,268 个 Work 文件＋`resource-site.json`：`check_schema --paths` ERROR 0；`check_v2 --paths` ERROR 0。`verify --strict` 全库 FAIL 35 条（悬空 entity_id／漂移），与 main 原状同为 35 条，非本批引入。

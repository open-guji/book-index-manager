## 二、Schema／数据格式（完整）
本块不新增字段。口径.md 逐项落到 `schema/common.md` 第三节、`schema/book.md` 第四节已有字段：
| 字段 | 取值／规则 | 可空 | 口径.md 要写清的点 |
|---|---|---|---|
| `resources[].id` | 站点 id：`nlc`、`kokusho`、`ndl`、`nat-archives-jp`、`npm`（故宫）等，沿用旧批次 | 否 | 站点 id 清单与对应站点；新站点怎么加（先问 A 块） |
| `resources[].types` | `image`｜`text`｜`physical`｜`catalog`｜`annotated` 的子集 | 否 | 每个值的判据；国書无影像条不写、不新造 catalog |
| `resources[].group` / `group_role` | 同内容镜像同 group；role＝origin／mirror／derivative | 可空 | 记录号放哪里（group 或 metadata）、何时拆新 group |
| `resource_groups[]` | label 标明版本或藏本 | 可空 | 多藏本时 label 写法 |
| Book `provenance[]` | institution＋call number＋seals | 可空 | 馆藏记录只进这里 |
| 层级 | Work 默认；Book 仅在资源明确对应该版本且该 Book 已存在 | — | 判「明确对应」的证据清单 |
| 每 Work 藏本数 | 同一来源机构 ≤3，取舍序＝全本影像＞版本明确＞卷数完整，总数不设硬顶 | — | 超出时被舍的怎么记（留在匹配表，不写库） |

一个真实样例：取 `Work/` 下已有 `resources` 的任一条，由 B 块抽样表给出，A 块定稿时填入口径.md（不凭记忆写样例）。

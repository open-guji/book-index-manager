# 分块设计：馆藏与在线资源挂接 ／ C 与录入排先后

> 块负责人：Silas（对口：Sabine，#576）　｜　项目主力：Silas　｜　状态：待评审
> 对应总计划：`项目进展/馆藏资源挂接/计划/总计划.md` 第四节第 C 行

## 一、本块目标与边界
目标：定出哪些 Work 现在就能挂资源、哪些要等录入或去重完，避免挂完被并条或重复挂。　｜　不做：不管录入本身；不改去重规则。　｜　交付物：`项目进展/馆藏资源挂接/计划/先后规则.md`。

## 二、Schema／数据格式（完整）
`先后规则.md` 规则表，每条规则含：编号、条件（可机器判定）、结论（现在可挂／等待／不挂）、依据。机器判定所需字段均为库内已有：`merged_into`、Work `id` 创建时间（id 解码）、`authors`、总目 heldBy（#383）。无新增字段。

## 三、程序架构
无新程序；规则供 D 块实现为过滤条件。判定样例用 `.claude/qa/mintid.py --parse` 解 id 时间。

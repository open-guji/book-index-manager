> **更正（LA 10-15，据 Reid〔R4〕在 GUJI-335 的实测，评论 11569）**：上表及结论中「200 / 均通 / 没有确认的死链」**只说明 HTTP 状态码为 200，对 nlc／ndl／kokusho／识典（shidianguji）／npm-rarebooks 不构成「链接真实可达」的证据**——这些站点对不存在的假 url 也返回 200（ndl 逐字节同；kokusho 4866B vs 4960B；识典 SPA 壳；npm 无会话 cookie 时一律 200 跳首页），nlc 的真假仅页面大小可区分（31249B vs 798B）。故本节「抽到的 200 条里没有确认的死链」对这五个站点**作废**；对 archive.org（假 id 返 404）、commons／wikisource（走 API／直查）仍成立。nlc／ndl／kokusho／nat-archives-jp／internet-archive 的「各 25/25 均通」中，仅 internet-archive 保持有效。补验方案见 `链接内容判据-补验方案-Silas.md`。

## 一、目标（一句话＋为什么）
把国图、故宫、国書、NDL、内閣文庫等外部馆藏与在线影像，按**新 schema（#568）**的口径准确挂到 Work／Book 上，使读者在条目页能点到真实可用的原书影像或馆藏记录。**质量先于数量**：宁可少挂，不错挂；存疑不写。#394 旧账（画像、六批写入、GLM 对照）当素材，不再按旧口径继续。

## 二、不做什么（先写）
- 不改 schema；需要改的另开卡给 Schema落地项目。
- 不改 Entity（朝代年号 #580、专名 #574 只借判据）。
- 不挂「存疑」档；不对国图存疑档全量跑 GLM（用户已定）。GLM 只当「同」的筛子，不用其判「异」。
- 不为挂资源而新建 Book 或 Work（新建归古籍总目录入 #576 与 P5b）。
- 不处理红楼梦版本图（归 #499）；#455 已处理的故宫 375 条挂错 Work 不重做。
- 不动正式库，除非 Marlowe 批；写 book-index／book-index-draft 前先在排班.md 登记；PR 由 Marlowe 审合。
- 不改网站展示；网站要什么先在跨号卡里问网站块。
- 抓取站点限速 ≥2 秒／次，不触反爬；凭据不进仓、不进 issue、不进聊天。

**新 schema 与旧口径的差别（实读 `schema/common.md` 第三节、`schema/book.md` 第四节）：**
- 本 schema 没有 `digitized` 字段。「有影像」「有文本」「只有馆藏记录」靠 `types`（`image`｜`text`｜`physical`｜`catalog`｜`annotated`）区分；馆藏记录另有 Book 的 `provenance`（机构＋索书号）。
- `resource_groups`：同一 `group`＝同一份内容的镜像；不同 `group`＝不同变体。
- Work、Book、Collection 都可挂 `resources`。

**判断：** 无资源 Work 占比（80.7%）不适合当主指标。历史上国書 D3 写入后挂资源率只从 29.47% 动到 29.54%，因为多数可匹配的 Work 已有别的资源。主指标改用「错挂率」和「确定档覆盖率」，占比只作参考。

## 五、总体架构与共用契约
**数据流：** 外部站点目录／已有匹配表（`book_index_json/library_data/_匹配/`）→ D 块统一匹配 → 确定／存疑／无 三档表 → 抽检（F）→ 通过才写 book-index（PR，Marlowe 审合）→ 网站块滚动发布。

**每个接口：**
| 接口 | 谁产出 | 谁消费 | 格式在哪里 |

## 六、项目验收标准
1. **错挂率：** 每个写入批次独立抽检，样本 ≥185 且全对（95% 置信下限 ≥98%）；否则整批不写。验证：抽检表。
2. **链接可达：** 每批抽 150 条链接 HTTP 200 全过；失败者剔除后复抽。验证：抽检脚本输出。
3. **格式零错：** 每个 PR 的 `check_schema`、`check_v2 --paths`、`verify --strict` 均 0 错；原始输出附 PR。
4. **存疑不写：** 随机抽已写入记录 100 条，对照匹配表，档位全为「确定」。
5. **不新增重复：** 写入后新增 dangling／exact 重复为 0（沿用 prcheck 口径）。
6. **旧账体检：** B 块出体检表，列清重复 id、错层、坏链数量，每类有处置结论。
7. **覆盖（参考，非硬指标）：** 确定档（国图／故宫／NDL／内閣）写入完成率；新有资源 Work 数以实测为准，不预先承诺占比。

## 附：口径提案（供 Marlowe 评审，A 块的出发点，尚未定稿）
1. **挂在哪一层：** 默认挂 **Work 层**，多个来源用 `resource_groups` 的 label 标明版本或藏本。仅当资源明确对应某一具体版本、且库内已有该版本的 Book 时，挂 **Book 层**。不为挂资源新建 Book。
2. **`types`：** 纯影像写 `["image"]`；站点另提供文本才加 `"text"`。`physical` 只给 Book 层「馆藏记录无影像」的情形；国書无影像条不写、不新造 `catalog`。
3. **馆藏记录：** 放 Book 的 `provenance`（机构＋索书号），不写成 resource。
4. **id 与 group：** 沿用 `nlc`、`kokusho`、`ndl`、`nat-archives-jp` 等站点 id，记录号放 `group` 与 `metadata`，与旧批次一致，不迁移。
5. **每个 Work 的藏本数：** 内閣文庫第 3 批的倾向是每 Work ≤3 个藏本（网站经理 10-10 确认展示正常）。其他来源是否沿用同一上限、超出时按什么排序取舍，待 Marlowe 评审时定。

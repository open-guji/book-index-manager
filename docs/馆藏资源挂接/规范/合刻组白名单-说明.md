# 合刻组白名单（GROUP_SPLIT 放行名单）

- **文件**：`合刻组白名单.tsv`（本目录，UTF-8，制表符分隔，首行表头）。**只由 Sabine（或其指定人）增行**，资源线只读。
- **含义**：站点的同一「同书成组」`group_key` 内各条记录，确定档指向 >1 个 Work 时，通常整组降存疑并加 `GROUP_SPLIT`；名单内的组**免于 GROUP_SPLIT 降级**，各条按各自 Work 的确定档照常处理（合刻本各册对各自 Work 正确）。
- **列**：`group_key`（必填，如国書 4368297）｜`site`（kokusho／ndl／nlc…，必填，同 key 不同站点分开写）｜`涉及Work`（逗号分隔 Work id；填了则只放行指向这些 Work 的行，其余 Work 仍按 GROUP_SPLIT 降；留空＝该组任意 Work 均放行）｜`说明`｜`确认人`｜`确认日期`（LA）｜`依据`（评论链接或文献）。
- **规矩**：每确认一组加一行；不得删行（撤销用新增一行写「撤销」于说明并清空 group_key 前加 `#`）；增行即时生效，Everett 的引擎每次运行读取最新 main。
- **种子**：4368297（kokusho；奇經八脈考等合刻组），涉及 Work 列待 Sabine 补全。

## 每位帝王的做法
1. **现状列**：
   - 「无条」：先用 `index/entities` 与 CBDB 同名查一遍确认真无条（同名异朝代不算），再建。
   - 「有同名条但朝代不符或未填，待消歧」：按候选 id 读条，用生卒、在位、年号三项核；是同一人→**不新建**，补朝代/period/dynasty_basis（及缺的 alt_names：庙号、谥号、字）；非同一人→新建并在 ai_note 注明与候选的区别。拿不准的不改，列入 PR 描述「待人审」。
2. **主名**＝需求单「拟本名」（R1 口径）。`alt_names` 收：庙号、谥号、年号称呼（如「某某帝」）、别名，type 用 schema 枚举，不确定的 type 别硬配。
3. **字段**：`dynasty`＋`dynasty_basis`（写依据，如「帝王年号對照.tsv 行」＋史源）；`dates`（生卒，有则填 basis；无可靠来源**留空**，不推）；在位起止写入 ai_note 或 schema 允许的字段；`external_ids.cbdb_id`（只在 CBDB 名字+朝代+生卒唯一吻合时填，`cbdb_match` 记档）；`review: unreviewed`。
4. **mint id**：`python3 .claude/qa/mintid.py --type Entity --lane <你的lane> -n N`；同步更新 `index/entities/<shard>.json`（id、primary_name、path、cbdb_id、生卒年）。
5. **证据**：每条至少 2 个独立来源互证（对照表来源列＋CBDB／正史），写入 ai_note；单源的标「单源」并列入 PR 描述。
6. **无源 10 对**（張玄靚、劉熙、沮渠牧犍、朱聿粵、張士誠、安慶緒、洪秀全、朱泚、耶律夷列、耶律直魯古）：建档前必须找第三来源核，核不到的**不建**，列入待办。落在哪批的哪人自查。
7. **宁缺毋滥**：不确定的字段留空，不猜；不改他人已有字段（除上面消歧补空）。
8. **自检**（PR 前必跑）：`python3 .claude/qa/verify.py --strict`；`python3 .claude/qa/check_v2.py`；`git diff --name-only origin/main… | python3 schema/check_schema.py --paths -`。`build_derived --check-only` 本机跑不了就在 PR 里写明。
9. **回填**：每批完成后在本目录放 `批X-id对照.tsv`（拟本名、朝代、新建/并入、entity_id、待人审标记），供 ruler.entity_id 回填卡用。

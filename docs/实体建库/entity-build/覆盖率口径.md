# 常见实体覆盖率：口径一页（人物／地名／官署／年号）

> GUJI-388｜口径依据 `总计划.md` §4（2026-10-14 已定）；本页只固化「分母、N、取样、命令」，不改口径。
> 数字由只读脚本对两仓 main 实跑得出，live＝`type=entity` 且无 `merged_into`。

## 一、人物
- **分母**：在 ≥2 部 Work 的 `authors[]` 中出现的名字（N≥2，按名字符串去重），剔除非人名（佚名、官撰、机构，规则见 `scripts/entity/人物覆盖率.py` `classify()`）；只在正文出现者不入分母。
- **建档率**：分母中名字已链到 live 人物 Entity 的比例（取该名下出现最多的 `entity_id`，核其为 live people）。
- **CBDB 对齐率**（参考）：上项中 Entity 带 `external_ids.cbdb_id` 的占分母比例；CBDB 判定「未收录」者另列、不入此分母。
- **命令**：`python3 -I scripts/entity/人物覆盖率.py <book-index> [未链接清单.tsv]`

## 二、地名
- **旧口径**：分母＝草稿库 `place` 按 `primary_name` 去重数；分子＝其中在正式库 live `place` 有同名者（主名或 alt_names 命中）。
- **新口径**（2026-10-14 Mirren 提议、Marcus 同意）：分母＝被 live 人物 `native_place` 引用、且（草稿或正式库已有同名地名，或引用人数 ≥T）的去重地名；分子＝其中正式库 live 有同名者。B 档（草稿有、无人引用）不入分母。
- **T（取样阈值）**：默认 20；脚本同时给 T=10／50 的敏感度。籍贯为自由文本，按字符串全等取名，不做别名归并、不区分同名异地，**所有地名新口径数字均为上界，汇报必须带「上界」二字**。
- 报告时两个数都列。

## 三、官署
- **分母**：草稿库 `office_level=concrete` 条 ∪ 正式库 live concrete 中主名不在草稿 concrete 内者（分子未必 ⊂ 草稿，取并集保证分子≤分母；2026-10-15 实测余 0 条，分母＝1,511）；概念条（concept）不计；官职（職事官／貼職／差遣／寄祿官／散官／加官）不计。
- **分子**：正式库 live `office_level=concrete` 条数。
- **与旧数 7.1% 的差**：7.1%＝107／1,511（10-14，main `5a7aea0feb`）；分母不变，分子由 107 增至 212（此后官署升格批次合入 main），故现为 14.0%，非口径变化。

## 四、年号／朝代
- 封闭集，分母＝历史上全部朝代与年号清单，分子＝已建档且帝王—年号—朝代三向对得上者；对账脚本 `scripts/entity/R9-年号封闭清单对账.py`（本卡不涉及）。

# 弱证档（2,717 人）抽样核实结论（Sidney，2026-10-14 洛杉矶时间）

对象：`N≥2剩余清单-Sidney.tsv` 中「回挂·无旁证·低」2,717 人（仅「批B新建同名 Entity＋朝代一致」）。
明细：`弱证档抽样核实-Sidney.tsv`（抽样 211 人逐个判定）、`弱证档全量机检标记-Sidney.tsv`（全 2,717 人机检标记＋建议）。

## 方法
1. **抽样 211 人**：Work 数 ≥6 的 90 人**全取**（普查）；Work 数 2–5 的 2,627 人按 Work 数×著录朝代分层随机抽 121 人（种子 20261014）。
2. **判据（均来自 main 上 Work 自带信息，不外联）**：①Work 作者条所引《中國古籍總目》人物号是否唯一（总目自己区分人）；②总目 author_info 的朝代前缀与 Entity 朝代是否冲突；③各 Work 最早版本年（康雍乾…民國）跨度与 Entity 朝代是否矛盾；④是否非人名；⑤题名堂号／别集名是否同源。机检有标记的 12 人逐个读了作品＋版本；无标记者看题名、author_info、版本通读一遍。
3. 同一套机检对全 2,717 人跑了一遍（见全量标记表）。

- 异人率点估计 ≤2%，上界略超 2%：建议**回挂 2,643 人（未被标记者，约 6,747 行 Work）**，**74 人（245 行）剔出**；江朝宗先修 Entity 朝代，陳枚、王元勳进人审，趙氏剔出分母。
- 同名多 Entity 在该档为 0（已剔）。

## 局限（须知）
- 判据是「总目人物号＋朝代＋版本年代」的内部一致性。总目若把两个**同名同朝代**的人并在同一人物号下，本地数据无法发现；CBDB 对这批无候选，亦无补救。这是残余风险，量级无法由本抽样估出。
- 「最早版本跨度」常因后世重印而虚高，故只作标记、不作定论（金聲、丁有煜等已核为同人）。

# R8b 消歧试验结论（Sidney，2026-10-14 洛杉矶时间）

对象：801–2000 CBDB 候选表里 none 且理由为「同名N人，无法唯一」的 311 人；抽 50（按同名人数×Work 数分层，种子 1014），其中 3 人现已无未挂 Work（已被他 PR 处理），有效 **47 人**。候选明细：Simone `R8b消歧试验-CBDB候选明细-Simone.tsv`（CBDB_20240208，205 条）。逐人结果：`R8b消歧试验-结果-Sidney.tsv`。只出表，不改 Entity。

## 方法
候选先按**朝代**过滤（Work 著录朝代 vs 候选朝代；候选朝代缺／「未詳」不排除，清与民國互容）；再找**正面证据**：候选别名出现在 Work 题名／总目 author_info，候选著述 TextName 与 Work 题名相合（≥3 字），候选籍贯出现在题名／author_info（**不**在馆藏摘要里找，避免馆藏地名误中）。

## 结果（47 人）
| 结论 | 人数 | 占比（95% 区间） |
|---|---|---|
| 强：唯一候选有别名／著述／籍贯证据 | 11 | 23%（14–37%） |
| 弱：仅朝代过滤后唯一（7 人为「唯一非稀疏候选」，11 人为朝代唯一） | 18 | 38% |
| 不可：过滤后仍多个、无证据 | 13 | 28% |
| 无解：朝代全不相容 | 4 | 9% |
| 多：两个以上候选皆有证据 | 1 | 2% |

## 结论
- **放宽到按著述／别名消歧，可行率约 23%（强档）**；叠加「仅朝代唯一」的弱档也只到约 60%，而弱档无正面证据，不建议写 cbdb_id，至多标「候选待证」。
- 311 人外推：强档约 70 人（区间 44–115），只在人工抽验后才可写 cbdb_id。
- 大量候选是 CBDB 新增的稀疏记录（无生卒、别名、著述、籍贯），它们既拿不出证据也排除不了，是不可档的主因。
- 强档 11 例的依据多为「Work 题名里含候选别名」（如《晴坡吟稿》↔周棨 號晴坡），属可靠但单一来源；按本团队规矩，写入前仍应逐条核一次。

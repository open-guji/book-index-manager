## 二、蔡超（hixhd2h9bn86、hixhiifgover → hixhd2h9bl64 蔡超宗）→ 独立确证，并
独立证据（不依赖库内 09-03 旧判断）：
1. 《經義考》「蔡氏（超）儀禮注（新舊唐書俱作蔡超宗）／陸德明曰蔡超字希遠濟陽人宋丞相諮議叅軍」——点明二名为一人。
2. 《隋志》「宋丞相諮議參軍蔡超」注《集注喪服經傳》二卷；《補宋書藝文志》：「丞相咨議參軍蔡超宗《集注喪服經傳》二卷」——同官同书同卷数，一书两名。
3. 《冊府元龜》卷606（四庫本，維基文庫）：「蔡超宗（字希遠），丞相諮議參軍，撰《集注喪服經傳》二卷」，与裴松之、雷次宗等同列——外部独立文献，名作「超宗」，字、官、书同上。
4. 库内书仪 d59f27s6r6rs 作者备注亦据《宋書·南郡王義宣傳》《釋文敘録》定为蔡超宗。

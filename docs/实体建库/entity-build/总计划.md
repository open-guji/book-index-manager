### 4.1 口径（用户 10-14 已同意简化口径；Mirren 指示写入本节）
- **N（频次阈值）＝ ≥2 部 Work**：人物分母取在 ≥2 部 Work 的 `authors[]` 中出现的人名。

- **CBDB 对齐率分母排除未收录者**：CBDB 确认无此人（判定为 none 且理由为“未收录”）者不入分母，单列。

- 草稿 place 有 925 行、905 个去重名；正式库 live place 171 条，同名映射为 171（全部在草稿集内）。

- 原“1,780 条未升格、117 作废”说法已过期：以本节实测为准。
- **地名口径改定（2026-10-14，Mirren 提议、Marcus 同意；Morgan/用户已同步）**：
  - 旧口径：分子 live place 171／分母草稿去重名 906 = **18.9%**。
  - 新口径：分母 = 「被人物籍贯引用的去重地名」，只做被引用的——A 档（草稿已有且被籍贯引用）160 名先做，C1 档（无草稿且引用 ≥20 人）107 名第二轮；B 档（草稿有但无人引用 575 名）、C2/C3 不做。完成后约 **48%**。

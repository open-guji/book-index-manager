## 二、置信定义
- **高**：CBDB 籍贯记录含省／府名（如"江西省-南昌府-新建縣"），且与目标条一致。
- **中**：无省名，只靠简称，按核省规则默认（如山陰→浙江，限明清人）。回挂前建议 Simone 抽核（已在做）。
- 判定为**转人审**＝规则要求不挂，或朝代段不合，或草稿无该条。不是"错"，是"不替人拍板"。
- 覆盖比：人物生卒（缺则生年+40，再缺则朝代区间）落入县条各段的比例；139 人只有朝代，精度较低。

## 三、遗留转人审 140（+2）的处理建议
- **長安 70**：唐宋及以前"長安"多指京兆，草稿条是明清西安府長安縣。建议：要么给長安縣条补唐宋段后再挂，要么这批长期留人审。
- **新城 19**：江西建昌府 8 人待新城縣(建昌府)条建成后补检覆盖再挂；其余无省名者（含疑山東新城王氏）人审。
- **新昌 16／永豐 16**：仅简称，规则要求不挂；可由读传记者按人补省。
- **山陰 14**：非明清且无省名，不默认。賀德仁、孔紹安（覆盖不足）+2。
- **其余**：華亭 1、山陽 2、嘉定 1，各有备注。

## 四、局限
1. 目标条 id 均是草稿库 id，须晋升后才能回挂。
2. 只核省份和年代，没核县名变化：山陽 1228–1276 名淮安縣；永豐(廣信) 1731 起名廣豐縣；新昌、嘉定有州段。
3. 判定证据全靠 CBDB 籍贯；CBDB 空白或笼统者只能转人审。
4. 此前口径"江西新城 11 人"有误，实为 8 人。

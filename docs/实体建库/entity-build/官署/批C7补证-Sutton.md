## 太府寺（宋）
- 出處：宋史 卷165（職官五）「太府寺」條，首句（設官句）
  - 原句：舊置判寺事一人，以兩製或帶職朝官充；同判寺一人，以京朝官充。
  - 取文：https://zh.wikisource.org/w/index.php?title=%E5%AE%8B%E5%8F%B2/%E5%8D%B7165&action=raw
- 出處：宋史 卷165（職官五）「太府寺」條，任官句
  - 原句：紹興元年，復以章億守太府寺丞，措置印給茶鹽鈔引，續添置丞二員。
  - 同上取文。

## 史館（宋）
- 出處：宋史 卷164（職官四）史館設置句
  - 原句：卽秘書省復建史館，以修神宗、哲宗實録，選本省官兼檢討、校勘，以侍從官充修撰。
  - 取文：https://zh.wikisource.org/w/index.php?title=%E5%AE%8B%E5%8F%B2/%E5%8D%B7164&action=raw
- 出處：宋史 卷164（職官四）史館改名句
  - 原句：四年，詔以史館爲名。
  - 同上取文。
- 注：史館為機構，上列句為設館句，不是某一官職的任官句。依 Mirren 裁定屬 collective 類，是否計入官署分母待用户定，本補證不升。

## 吏科（明）
- 出處：明史 卷74（職官三）六科條，設官句（給事中員額）
  - 原句：吏、戶、禮、兵、刑、工六科。各都給事中一人，正七品；左、右給事中各一人，從七品；給事中，吏科四人，戶科八人，禮科六人，兵科十人，刑科八人，工科四人，並從七品，後增、減員數不常。
  - 取文：https://zh.wikisource.org/w/index.php?title=%E6%98%8E%E5%8F%B2/%E5%8D%B774&action=raw
- 出處：明史 卷74（職官三）吏科職掌句
  - 原句：吏科，凡吏部引選，則掌科即都給事中，以掌本科印，故名，六科同。
  - 同上取文。

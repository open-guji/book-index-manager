## 二、收尾口径建议

1. **人物（可算）**：分母＝多作品作者（≥2 部 Work）按名去重，现为 **16,545**；收尾指标用 **建档率 79.0%**。CBDB 对齐率作参考，报 **51.0%**（占分母）或 64.6%（占已链接）。按用户简化口径，CBDB 不设收尾门槛，单列「待证」。
2. **地名、官署**：main 内只能给**已升格数**（地名 171、官署 59）。收尾比率需要先定分母来源（书目籍贯 ＋ 总目文本频次 ≥N 的名单），这一步不在 main 实测范围。建议 Mirren 指定由谁出分母清单后再算。
3. **朝代**：139 为封闭集。建议收尾指标直接写「139／规范朝代表行数」，需先核对 schema §九 的行数。
4. **年号**：封闭集在 repo 内没有。建议用一份外部封闭清单（如 CBDB 年号表）作分母，否则只能报绝对数。

**给用户／Mirren 拍板的 3 件（同总计划）**：① 频次阈值 N（人物建议先用「≥2 部 Work」，即本次口径，免去总目文本频次统计）；② 人物分母是否含「只在正文出现、不在书目作者里」的人（本次未算，建议暂不含）；③ 对齐率分母是否排除 CBDB 未收录者（建议排除，单列）。

## 三、已知偏差（实测局限）

- **非人名混入未链接部分**：抽样未链接名含「佚名」「不著編人」「國史館」「學部編譯圖書局」等，属无名或机构著录，应在分母里剔除。本次未逐一筛除，**分母 16,545 可能偏大**，剔除后建档率会略升。
- **名字形式不一致**：如「愛新覺羅·弘曆」与常用名「弘曆」，按字符串匹配会漏链。建议收尾前做一次别名归并（alt_names）再算。
- **链接只按名字符串**：同名异人会被统一到出现最多的 entity_id，可能掩盖误挂；这一项属于人审，不在本次口径内。
- **Book 的责任者未计入**：仅统计 Work 的 `authors[]`。

## 独立性判定规则（verdict_check.py 用）
- **同链**：维基的备注若写明「见《X》」且 DILA 同样出自该书，则两者在该条上视为同链、按单源。当前无法逐条证实 DILA 的上游，故保守约定：**两源起年一致且年号名一致 → 记「双源一致」；起年相差 ≥2 或名不一致 → 记冲突，须第三源（CBDB 或纪年书）才能 adopt。**
- 「双源一致」≠「已核实」：两者可能共出一个纪年表上游（弱独立）。因此裁决 adopt 时 note 要写「两源一致；上游未证」，抽检（Sylvie）才可升 reviewed。
- 维基独有、DILA 缺的（如吳越、閩、南唐、民变年号）：不是错，是 DILA 覆盖面所限，单源 → `open`，由裁决人查第三源。

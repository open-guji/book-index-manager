# 分块设计：朝代年号录入 ／ A 来源与分母基线

> 块负责人：Sasha　｜　项目主力：Sasha　｜　状态：待评审（2026-10-12 洛杉矶 15:50）
> 对应总计划：`项目进展/朝代年号录入/计划/总计划.md` 第四节第 A 行

## 一、本块目标与边界
目标：把外部权威来源统一抽取成同一格式的**源表**，评出各来源的可信度与独立性，测出「分母」（≥2 个独立来源并集去重后的中国年号数），供 B（对勘）、C（裁决）、E（帝王）使用。
不做：不对库内条目做裁决（归 C）；不写对勘脚本（归 B，Edwin）；不把外部库的描述性文字或外部 id 带进数据仓；源表只放 overview，不进数据仓。
交付物：`源表/*.tsv`（每来源一份）、`来源可信度表.md`、`分母.md`（数字＋命令）。

## 二、Schema／数据格式
**源表**（与 #580 上已通知 Edwin、Sylvie 的一致）：TSV，UTF-8，首行 `#` 注释写来源 URL 与取数时刻（洛杉矶），第二行为表头。

| 列 | 类型 | 可空 | 含义 |
|---|---|---|---|
| 来源 | 字符串 | 否 | 来源代号：`zhwp-中国年号列表`、`dila-time`、`cbdb-nianhao`、`jinian-X` |
| 源内键 | 字符串 | 否 | 该来源内的行号或 id（仅用于回查原页，不进库） |
| 年号 | 字符串 | 否 | 源写法，原样（含简繁异体），**不在抽取时改写**；归一由 B 做 |
| 朝代(源写法) | 字符串 | 是 | 源写的政权名 |
| 帝王(源写法) | 字符串 | 是 | 源写的君主，原样 |
| 起／止 | 整数 | 是 | 公元年，公元前负数、无 0 年；解析不出留空，不猜 |
| 备注 | 字符串 | 是 | 含原文起讫字符串（便于回查）与来源备注，截 80 字 |

真实样例（已产出的 `源表/zhwp_中国年号列表.tsv` 第 3 行）：`zhwp-中国年号列表	r1	建元	西漢	汉武帝 劉徹	-140	-135	前140年－前135年 | 用亥正。…`

**可信度表** `来源可信度表.md`：每来源一节，写：①是什么（编者、版本）；②覆盖范围（朝代、政权类型）；③上游是谁（判断是否与别源同源）；④许可与用法（只对勘，不搬运）；⑤已知缺陷（实测）；⑥计入「独立来源」与否。
**分母** `分母.md`：定义（≥2 个独立来源都有、按（归一年号，政权，起年±1）去重）、数字、命令、各来源单独的行数与覆盖。

## 三、程序架构
- `scripts/extract_wp.py`（已写）：解析维基「中国年号列表」HTML → 源表。
- `scripts/extract_dila.py`（新写）：逐朝代请求 `authority.dila.edu.tw/time/search.php?chk=nextLevel&dpk=<朝代>`，限速每秒 ≤1 次，原始 HTML 缓存到暂存区，解析成源表。
- `scripts/extract_cbdb.py`（新写，条件步）：从私有仓 `open-guji-core/cbdb-archive` 取 `NIAN_HAO`、`DYNASTIES` 两表导出为源表；仓里没有就在 `来源可信度表.md` 记「未取得」。
- `scripts/denominator.py`（新写）：读全部源表，归一（繁简、避讳异体用 B 的归一函数；B 未交前先用 opencc 或自带小表），算分母。
- 运行在云端会话；原始 HTML 与缓存不入仓，源表入仓。

## 七、风险与未决
- **最可能出错的一处**：把「维基抄自纪年表」的两个来源当成独立来源，使分母虚高或对勘假一致。对策：可信度表第③项必须写上游，同上游只算一个。
- 初测发现：维基页含 南詔／大理、高昌、渤海、吳越 等边疆与割据政权（该源 1,279 行 vs 库内 734 条），**这些是否都属于「中国年号」收录范围是总计划没写的口径**，须在步 6 前由 Mirren／Sasha 定：默认以「库内已有政权清单＋同类割据政权」为范围，边疆政权单列不计入分母，列清单交 C 裁决。
- 维基页是简繁混排（如「汉武帝」「建元」），归一需统一，由 B 实现。
- CBDB 许可 2026-08-20 起已改，只对勘不搬运。
- 若 DILA 或 cbdb-archive 取不到，独立来源可能只剩 1 个：则分母标「初报」，并在 C 的裁决规则里把「≥2 源一致」降为「1 源一致＋学者复核」，需 Mirren 同意。

> 块负责人：Sylvie（文献学者，账号 B 实体）　｜　项目主力：Sasha　｜　状态：评审通过（2026-10-12 洛杉矶）
> 对应总计划：`项目进展/朝代年号录入/计划/总计划.md` 第四节第 E 行

## 一、本块目标与边界
目标：把库内 734 条年号涉及的每一个（帝王，朝代）对，建成一张可溯源的纪年对照表（本名／庙号／谥号／在位起止／年号序列），统一 `ruler.name` 口径，并把无人物条的帝王列成需求单给 Soren。
不做：不改 schema；不建人物条（Soren）；不直接改 dynasty／reign 条目（口径改动清单交块 C 执行，PR 归 C）；不碰地名官署、Work／Book；不存 `cbdb_*`／DILA／CHGIS id；不整表搬运外部库，外部库只作对勘，表内文字自写；不收民国、域外年号（块 G）。
交付物：`帝王年号对照.tsv`、`ruler口径规则.md`、`ruler改名清单.tsv`（交 C）、`帝王需求单-Soren.tsv`、`遗留-E.md`。均放 `项目进展/朝代年号录入/` 下，不进数据仓。

## 二、Schema／数据格式（完整）
**1. `帝王年号对照.tsv`**（UTF-8，首行表头；对应总计划第五节「帝王对照表」契约，前六列与契约一致，后列为本块追加，不是 Entity schema 字段）

| 列 | 类型 | 可空 | 含义 |
|---|---|---|---|
| 本名 | 字符串 | 否 | 统一口径后的名，规则见 `ruler口径规则.md`；无名可考者写通称并在备注说明 |
| 庙号 | 字符串 | 是 | 如「太祖」；无则空 |
| 谥号 | 字符串 | 是 | 如「啓運立極英武睿文神德聖功至明大孝皇帝」可写全称，或写简称并在备注标明 |
| 朝代 | 字符串 | 否 | 与库内朝代条 `primary_name` 一致（如「趙宋」「北宋」以库内为准，不自改） |
| 在位起止 | `起~止` 整数 | 是 | 公元年，前为负，无 0 年；年号以外的在位年，来源不足时空 |
| 年号序列 | `名(起-止)` 以`；`分隔 | 否 | 取自库内 reign 条，按起年升序 |
| 库内ruler.name | 字符串 | 否 | 库内现写法（多种写法用 `｜` 分隔） |
| reign_ids | 字符串 | 否 | 该对下年号条 id，`,` 分隔 |
| 来源 | 字符串 | 否 | 每行至少一个来源（书名卷次或站点＋取数时刻）；一个来源写一个，≥2 个独立来源标「已对勘」，仅一个标「单源」 |
| 备注 | 字符串 | 是 | 异说、同名异人（如桓玄在桓楚／東晉两朝代）、需消歧处 |

样例：`趙匡胤｜太祖｜（谥号全称待源表）｜北宋｜960~976｜建隆(960-963)；乾德(963-968)；開寶(968-976)｜趙匡胤｜hixi1uborq53,…｜（来源）｜`（样例仅示格式，谥号／来源列数据待步 3 取得，现在不填）。

**2. `ruler口径规则.md`**：每条规则一句可复核的话（如「去氏族前缀，取人物库主名；人物库无条者取通行称呼」），附例外表。
**3. `ruler改名清单.tsv`**：`reign_id｜现ruler.name｜拟ruler.name｜规则编号｜依据`，交块 C 执行。
**4. `帝王需求单-Soren.tsv`**：`拟本名｜朝代｜庙号｜在位起止｜人物库现状（无条／同名异人待消歧）｜依据来源`。
**5. `遗留-E.md`**：不能结案的行逐条列出（含原因、谁接）。

## 三、程序架构
- `scripts/ruler_pairs.py`（新写，云端会话跑）：遍历 book-index 的 `Entity/**/*.json`，产出（帝王，朝代）对表＋年号序列。复用 `scripts/ruler_probe.py` 的遍历写法。
- `scripts/ruler_probe.py`（复用）：对人物库按主名＋别名精确匹配，复核「无条」数。
- 入口：`python3 scripts/ruler_pairs.py <book-index 根> > 对照底表.tsv`；输出带库指纹（commit 前 10 位）。
- 取数：来源表读块 A 的 `源表/*.tsv`；A 未交前，步 3 不开工。其余步骤只读库内数据，在云端会话跑，无需服务器。

## 七、风险与未决
- **最可能出错的一处**：步 2 口径。「氏族前缀去不去」没有天然标准（人物库主名、史书通称、本名三者常不一致），若不先定规则就改，会改出新的不一致。默认做法：规则由 Sasha 拍板，拿不准的帝王不改，只列例外。
- 总计划写 376 对，我浅测为 377 对，须在步 1 对齐；在对齐前，验收分母用脚本实测值，不取总计划的数。
- 同名异人：桓玄（桓楚／東晉）、愛新覺羅皇太極（後金／清）、武則天（武周／唐）、朱泚（秦／漢）按朝代分行，不合并，备注写明。
- 依赖块 A：步 3 在 A 源表未交前无法开工；A 迟到则本块只能先交步 1、2、5。
- 待 Sasha 定：谥号写全称还是简称（默认：写史籍常见简称，全称仅在有源可引时补）。
- 不改库内数据，改库是 C 的 PR。

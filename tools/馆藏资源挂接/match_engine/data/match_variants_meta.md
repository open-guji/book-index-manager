# match_variants.json — 比对归一字典

## 用途

查重脚本在比较 title / author.name 时，用本表把每个字符替换为等价类的 canon 字符。
**不写回 Work 库**。仅作"比对键"。

## 数据来源

| 来源 | pair 数 |
|---|---:|
| existing_22 | 24 |
| guji_variants | 81 |
| opencc_st | 3741 |
| opencc_ts | 4057 |
| opencc_jp | 366 |

## 输出

- 等价类总数：4011（多元素的）
- 映射条目：**4355**
- canon 选择：unicode 最小（确定性）

## 抽样

- canon=`宁` 等价类: `宁`, `寧`, `甯`
- canon=`說` 等价类: `說`, `説`, `说`
- canon=`戶` 等价类: `戶`, `户`, `戸`
- canon=`为` 等价类: `为`, `為`, `爲`
- canon=`並` 等价类: `並`, `併`, `并`, `竝`
- canon=`乡` 等价类: `乡`, `郷`, `鄉`, `鄕`
- canon=`疎` 等价类: `疎`, `疏`, `踈`
- canon=`閑` 等价类: `閑`, `閒`, `闲`, `𫔮`
- canon=`消` 等价类: `消`, `銷`, `销`
- canon=`弁` 等价类: `弁`, `瓣`, `辨`, `辩`, `辯`
- canon=`桢` 等价类: `桢`, `楨`, `祯`, `禎`
- canon=`輯` 等价类: `輯`, `辑`, `集`

## 注意

- 一对多简化字（如 发→發/髮、台→臺/檯/颱）从 OpenCC 跳过，避免错合
- 30 UNKNOWN OCR 易混对（楨/禎、徵/澂 等）**不**进入本表，由人工流程处理
- 部分异体字归一会跨语义合并（如 后/後、于/於），但仅作比对键，不影响 title 显示
